1.2. Managementul Șabloanelor în src/context/AppContext.js:

export const AppContext = createContext();

export const AppProvider = ({ children }) => {
    const [viewMode, setViewMode] = useState('COCKPIT');
    const [selectedMetric, setSelectedMetric] = useState('RPM');
    const [activeTemplate, setActiveTemplateState] = useState('MOTORSPORT');
    const [tripReport, setTripReport] = useState(null);
    const navigationRef = useRef(null);

    useEffect(() => {
        AsyncStorage.getItem('@cockpit_template').then(saved => {
            if (saved && TEMPLATES[saved]) {
                setActiveTemplateState(saved);
            }
        }).catch(() => {});
    }, []);

    const setActiveTemplate = useCallback(async (tplId) => {
        if (!TEMPLATES[tplId]) return;
        setActiveTemplateState(tplId);
        try {
            await AsyncStorage.setItem('@cockpit_template', tplId);
        } catch {}
    }, []);

    const currentTemplate = TEMPLATES[activeTemplate] || TEMPLATES.MOTORSPORT;

    return (
        <AppContext.Provider value={{
            viewMode, setViewMode,
            selectedMetric, setSelectedMetric,
            activeTemplate, setActiveTemplate, currentTemplate,
            tripReport, setTripReport, dismissTripReport,
            navigationRef, setNavigationRef,
        }}>
            {children}
        </AppContext.Provider>
    );
};

2. STRUCTURA VIZUALĂ & JSX DIN LiveDashboardScreen.js
================================================================================

Ecranul dispune de telemetrie smooth la 60 FPS (useSmoothedTelemetry), comutator voluntar (🚗 RAPID vs ⚡ PRO) și 3 sub-tab-uri interne.

Top-Level Return:
<View style={[styles.root, { backgroundColor: tpl.bg }]}>
    {/* Top Bar */}
    <View style={styles.topBar}>
        <View style={[styles.connPill, { borderColor: connColor }]}>
            <View style={[styles.connDot, { backgroundColor: connColor }]} />
            <Text style={[styles.connLabel, { color: connColor }]}>{connLabel}</Text>
        </View>

        {/* Comutator RAPID vs PRO */}
        <TouchableOpacity style={[styles.modeTogglePill, proMode ? styles.modeTogglePro : styles.modeToggleDriver]}>
            <Text>{proMode ? '⚡ PRO' : '🚗 RAPID'}</Text>
        </TouchableOpacity>

        {/* HUD Windshield Mirror Toggle */}
        {tpl.isHud && (
            <TouchableOpacity style={styles.hudToggleBtn}>
                <Text>{isHudMirrored ? '🪞 MIRROR ON' : '🪞 HUD'}</Text>
            </TouchableOpacity>
        )}

        <Text style={styles.vehicleName}>{getVehicleLabel() || 'Dashboard'}</Text>
        <TouchableOpacity style={styles.alertBtn}><Text>🔔</Text></TouchableOpacity>
    </View>

    {/* Scrollable Content */}
    <ScrollView style={styles.scroll}>
        {tab === 'LIVE'   && renderLive()}
        {tab === 'PARAMS' && renderParams()}
        {tab === 'SCOPE'  && renderScope()}
    </ScrollView>

    {/* Bottom Tab Bar */}
    <View style={styles.tabBar}>
        <TouchableOpacity><Text>Bord</Text></TouchableOpacity>
        {proMode && <TouchableOpacity><Text>Parametri</Text></TouchableOpacity>}
        <TouchableOpacity><Text>Grafic</Text></TouchableOpacity>
    </View>
</View>

Sub-tab-ul LIVE conține:
1. Speed Hero (cifră mare în km/h cu tpl.speedColor)
2. Turometru & Bară RPM cu Redline Dinamic (2500 RPM motor rece, 3200 RPM încălzire, 4500 RPM optim)
3. Badge Motor Rece / În încălzire
4. Card Virtual Dyno & ECU Math (Putere CP, Cuplu Nm, Eficiență Volumetrică %, Lambda/AFR)
5. Indicator Dual Boost (Comandat vs Efectiv în bar cu alertă de pierderi admisie/VNT)
6. Sensor Fusion & Observatori Virtuali (BSFC în g/kWh, Uzură Ulei Arrhenius, Sănătate Baterie SoH, Energie Frâne MJ)
7. Grid 2x3 Metric Tiles (Temp, Boost, Voltaj, Consum, Scor Eco, Treaptă)
8. Asistent AI & Recomandare Contextuală
